A66A Safe Build

This is a local, non-money sandbox for learning. It does not process real-money lottery wagers or cash prizes.
Open index.html first.

Included: user registration/login, sandbox OTP, profile, purchased ticket list, blank/test payment area, admin dashboard, product CRUD, ticket sold/unsold view, user search, lottery-type + ticket-number lookup, settings.

Frontend localStorage is not production security. A real lawful service needs a server-side database, authentication, authorization, OTP provider and compliant payment provider.
